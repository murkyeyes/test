# Ảnh minh họa HK chat cho báo cáo

Các PNG trong thư mục này là ảnh chụp trực tiếp từ Android Emulator đang chạy HK chat với server local.

| Ảnh | Nội dung | Vị trí đề xuất |
| --- | --- | --- |
| `01-dang-nhap-server.png` | Nhập URL server và đăng nhập | Luồng người dùng 1 |
| `02-danh-sach-kenh-nhom.png` | Danh sách kênh và nhóm riêng Đồ án chuyên ngành | Đặc tả MVP |
| `03-hoi-thoai-do-an.png` | Hội thoại Huy, Khải, Tân, Đạt | Đặc tả MVP |
| `04-tra-loi-trong-hoi-thoai.png` | Tin trả lời có trích dẫn tin gốc | Luồng người dùng 2 |
| `05-tim-kiem-tin-nhan.png` | Tìm từ khóa MVP trong tin nhắn | Đặc tả MVP |
| `06-mo-lai-hoi-thoai.png` | Mở hội thoại từ kết quả tìm kiếm | Đặc tả MVP |

Khi chạm kết quả tìm kiếm, app hiện mở kênh chứa tin nhưng chưa tự cuộn tới đúng tin đó. Chú thích ảnh nên ghi “mở lại hội thoại”.

Chưa có ảnh thật cho GitHub Organization, Wiki, Project Board và Issue vì tài khoản GitHub đang kết nối chưa có Organization hoặc repository HK chat. Cần tạo các tài nguyên đó với tên nhóm và GitHub username thật trước khi chụp. Không dùng ảnh dự án khác để thay thế. Chưa có ảnh push vì HK chat chưa cấu hình Firebase/Apple push.
